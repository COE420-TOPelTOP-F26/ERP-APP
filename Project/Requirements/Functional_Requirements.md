# Functional Requirements — ONE System

| ID | Functional requirement | Source | Contributor |
|---|---|---|---|
| FR-01 | The system shall allow an employee to submit a leave request specifying the leave type, start date, and end date. | S-01 | Tala Abed |
| FR-02 | The system shall allow a manager to view pending leave requests from their direct reports. | S-01 | Tala Abed |
| FR-03 | The system shall allow a manager to approve or reject a leave request and shall notify the employee of the decision. | S-01 | Tala Abed |
| FR-04 | The system shall allow an employee to submit a travel expense claim with an expense category, amount, and attached receipt. | S-02 | Tala Abed |
| FR-05 | The system shall answer an employee's policy question using approved company documents and identify the source document. | S-04 | Tala Abed |
| FR-06 | The system shall allow an employee to view recorded attendance entry and exit times and total hours worked for a selected period. | S-03 | Nadine Alameldin |
| FR-07 | The system shall allow an employee to search the employee directory by name, department, or position. | S-03 | Nadine Alameldin |
| FR-08 | The system shall allow an authorized HR user to publish an announcement on employee dashboards and notify employees. | S-04 | Nadine Alameldin |
| FR-09 | The system shall allow an employee to request an extension of a borrowed IT asset's due date and route the request to their manager for approval. | S-05 | Nadine Alameldin |
| FR-10 | The system shall allow an employee to view the history and current status of their submitted requests. | S-02, S-05 | Nadine Alameldin |
| FR-11 | The system shall display an employee's personalized dashboard with attendance information, pending requests, notifications, and upcoming leave. | S-03 | Razan El Gendy |
| FR-12 | The system shall allow an employee to submit an IT support request with an issue category and description, receive a ticket number, and track its status. | S-05 | Razan El Gendy |
| FR-13 | The system shall allow an employee to search, view, and download company policies, forms, and documents they are authorized to access. | S-04 | Razan El Gendy |
| FR-14 | The system shall allow an employee to view their profile information and submit changes for HR verification. | S-02 | Razan El Gendy |
| FR-15 | The system shall authenticate an employee's login and restrict access to features according to the user's assigned role and permissions. | S-03 | Razan El Gendy |
| FR-16 | The system shall allow an employee to request the return of a borrowed IT asset and update its status after the return is recorded. | S-05 | Kholoud Elkholy |
| FR-17 | The system shall allow an employee to view the current status and latest updates of their IT support requests. | S-05 | Kholoud Elkholy |
| FR-18 | The system shall allow an employee to view company announcements, including their details and publication information. | S-04 | Kholoud Elkholy |
| FR-19 | The system shall allow an employee to report a payslip discrepancy by selecting the pay period, describing the incorrect earning or deduction, and submitting the report to the Finance Department. | S-02 | Kholoud Elkholy |
| FR-20 | The system shall allow an employee to view their authorized personal and contact information. | S-02, S-03 | Kholoud Elkholy |
