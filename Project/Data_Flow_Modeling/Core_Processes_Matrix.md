# Core Processes Matrix

This matrix describes the seven major processes (1.0–7.0) shown in the Level-0 DFD of the ONE ERP App.

| Process No. and Name | Input Data | Output Data | Rules |
|---|---|---|---|
| **1.0 Access and employee records** | Credentials; profile queries and changes; directory queries; administrator role changes; HR verification decisions; user records from D1. | Access result; profile and directory results; pending profile changes to HR; update confirmations; user and role updates to D1. | Validate credentials and permissions; restrict access to authorized profile and directory information; apply profile changes only after HR verification. |
| **2.0 Attendance and dashboard** | Attendance and dashboard queries; attendance records from the Attendance System; profile data from D1; attendance records from D2; request summaries from D3; IT status from D5; announcements and notices from D7. | Attendance summary and personalized dashboard; attendance queries to the Attendance System; imported attendance records to D2. | Display weekly entry and exit records and total hours worked; combine authorized employee information, request summaries, IT status, announcements and notifications on the dashboard. |
| **3.0 Leave and request history** | Leave requests; request-history queries; manager queries and leave decisions; leave and request-history records from D3. | Leave status and request history; pending leave requests and confirmations to the manager; leave updates to D3; leave decision notices to D7. | Validate leave dates and available balance; route requests to the employee's direct manager; record approval or rejection; generate a notification of the decision. |
| **4.0 Expenses and payslip enquiries** | Expense claims and receipts; payslip queries; discrepancy reports; Finance review outcomes; payslip records from ERP; cached payslips from D2; claim records from D4. | Claim status, payslips and discrepancy acknowledgements; expense claims and discrepancy reports to Finance; payslip queries to ERP; refreshed payslip cache to D2; request summaries to D3; claims and reports to D4; Finance notices to D7. | Validate positive claim amounts and receipt type and size; restrict payslip access to authorized users; retain the latest successfully retrieved payslip data; do not calculate salaries or process payments. |
| **5.0 IT assets and support** | Asset borrowing, extension and return requests; support issues and ticket queries; manager extension decisions; IT asset and ticket updates; asset and support records from D5. | Asset status, ticket numbers and support updates; pending extensions and confirmations to the manager; asset requests and support tickets to IT; request summaries to D3; asset and ticket updates to D5; IT notices to D7. | Check asset availability; route extensions to the manager; update returned-asset status only after IT confirmation; record support-ticket updates and preserve their history. |
| **6.0 Documents and ONEAI answers** | Document search and download queries; policy questions; approved document updates from HR; access permissions from D1; approved documents from D6. | Authorized documents and source-linked ONEAI answers; publication confirmations to HR; document updates to D6. | Check document permissions before retrieval; answer policy questions using approved, accessible documents; provide a no-answer response when supporting information is insufficient. |
| **7.0 Announcements and notifications** | Announcement and notification queries; announcement publication data from HR; announcements and notices from D7. | Announcements and notifications to employees; publication confirmations to HR; published announcements to D7. | Allow only authorized HR users to publish announcements; display notifications to the intended employees; include publication details and identify the request or event that triggered each notification. |
