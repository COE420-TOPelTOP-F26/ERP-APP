# Component Descriptions

## CO1 – Identity and Employee Records
- Log in and log out
- Automatic logout after inactivity
- Search the employee directory
- View and update personal profile and emergency contacts
- Manage user accounts, roles and permissions

## CO2 – Notifications and Announcements
- Receive notifications about requests and events
- View company announcements
- Publish and broadcast HR announcements

## CO3 – Requests, Approvals and IT Services
- Submit leave requests
- Approve or reject requests
- Track request status and history
- Request profile changes
- Borrow, extend and return IT assets
- Submit and follow IT support tickets

## CO4 – Company Content and ONEAI
- Search and download company documents
- Ask ONEAI policy questions
- Escalate an unresolved question to IT support
- Publish company documents (HR)
- Verify profile changes (HR)

## CO5 – Attendance and Dashboard
- View attendance records and weekly summaries
- View the personalized dashboard

## CO6 – Expenses, Payroll and ERP Integration
- Submit travel expense claims
- View payslips
- Report payslip discrepancies
- Review claims and discrepancy reports (Finance)
